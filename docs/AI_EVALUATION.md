# AI 问答人工评测与发布门

正式质量结论不得使用关键词命中率。`qa-benchmark` 只用于发现明显回归；发布判断必须使用本文件定义的人工复核流程。

## 评测集

首发评测集是 `config/evaluation/math-v1.json`，范围固定为 `数学 / 高一 / 人教A版`。当前文件为种子集，状态为 `draft`；数学内容负责人确认题目、参考要点和阈值后，才可将其状态改为 `approved`。

每道题至少包含：

- 唯一且稳定的 `id`；
- 问答模式、帮助级别和原始问题；
- 预期学科与参考要点；
- 是否必须有引用、是否要求纠正错误前提；
- 能说明覆盖面的标签。

修改已批准题目的问题或参考要点必须递增数据集版本。不得为提高分数删除失败题；需要废弃时保留旧版本和变更原因。

## 生成待复核运行

在与发布候选相同的数据库、模型、Prompt 和向量索引上执行：

```powershell
python -m app.cli qa-eval-run `
  --dataset config/evaluation/math-v1.json `
  --output qa-eval-math-v1-review.json `
  --workers 4
```

输出保存模型答案、实际学科路由、检索片段、供应商、模型、耗时和错误。`review` 初始状态一律是 `pending`，生成命令不会产生正确率。

## 人工复核

审核员必须逐题对照原始来源和 `expected_points`，填写：

| 字段 | 取值 | 含义 |
|---|---|---|
| `status` | `completed` | 表示该题已完成复核 |
| `reviewer` | 稳定审核员标识 | 不填写姓名、电话等额外个人信息 |
| `reviewed_at` | 带时区 ISO-8601 | 复核完成时间 |
| `correctness` | `0` / `0.5` / `1` | 错误、部分正确、正确 |
| `citation_supported` | 布尔值 | 引用是否真正支持关键结论 |
| `unsupported_claim` | 布尔值 | 是否出现来源无法支撑的事实或公式 |
| `correction_success` | 布尔值或 `null` | 仅纠错题填写，其余必须为 `null` |
| `helpfulness` | `1` 到 `5` | 对目标年级学生是否有实际帮助 |
| `notes` | 文本或 `null` | 缺陷、来源页和修订建议 |

同一发布候选至少由一名数学内容审核员完整复核。涉及公式争议、答案分歧或来源冲突的题目必须由第二名审核员复核并记录裁决，不能由模型自行裁决。

## 计算发布门

```powershell
python -m app.cli qa-eval-score `
  --run qa-eval-math-v1-review.json `
  --output qa-eval-math-v1-score.json
```

默认只要有一题仍为 `pending`，命令就失败。`--allow-incomplete` 只用于查看中间统计，生成的 `release_gate_passed` 永远为 `false`。

正式指标包括：执行成功率、学科路由正确率、回答正确率、引用命中率、无依据率、纠错率和平均帮助度。阈值由版本化数据集记录，不能在评分后临时降低。发布证据应同时保存：

1. 已批准数据集；
2. 原始待复核运行；
3. 已完成人工字段的复核文件；
4. 评分报告；
5. 使用的后端提交、Prompt 版本、知识索引 SHA-256 和审核人。

## 九学科分期

当前只有数学属于首发正式学科。其他学科可以建立 `draft` 种子集和运行回归，但在来源授权、内容审核、人工评测和试点结论齐备前，不得用数学评测结果代替，也不得宣称达到正式发布门。
